# Privacy Policy

## Unciv does not operate the community multiplayer servers

Online multiplayer data is handled by the community server selected in the game, not by an
Unciv-operated multiplayer service.

## Online multiplayer uses third-party servers

When you enable online multiplayer, the server you select receives your player ID, IP address,
game save, and game preview data so it can exchange turns. Server passwords are also sent to that
server for authentication. On iOS, those passwords are stored locally in the Keychain and the app
only accepts HTTPS API v1 servers.

The Unciv project does not control community multiplayer servers. Their operators determine service
availability, retention, access, and deletion policies. Use a server only if you trust its operator;
you can select a different server in the Options menu.

On supported non-iOS builds, choosing **Download music** fetches "Thatched Villagers" directly
from the artist's `incompetech.com` HTTPS server. That server receives ordinary request metadata,
including your IP address. The download is optional and is disabled in the iOS build.
