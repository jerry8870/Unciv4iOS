Χτίστε τον πολιτισμό σας, ερευνήστε τεχνολογίες, επεκτείνετε τις πόλεις σας και νικήστε τους εχθρούς σας!

Ο κόσμος περιμένει! Θα χτίσετε τον πολιτισμό σας σε μια αυτοκρατορία που θα αντέξει στη δοκιμασία του χρόνου;

Η άδεια «πλήρης πρόσβαση στο δίκτυο» απαιτείται για λήψεις που ξεκινά ο χρήστης και για τη λειτουργία πολλών παικτών. Όλες οι άλλες αναφερόμενες άδειες περιλαμβάνονται αυτόματα από το API που χρησιμοποιείται για τις ειδοποιήσεις γύρων πολλών παικτών. Οι άδειες δικτύου χρησιμοποιούνται για την εμφάνιση της λίστας των mod, τη λήψη mod και μουσικής, καθώς και για την αποστολή/λήψη παιχνιδιών πολλών παικτών. Το Unciv δεν ξεκινά καμία άλλη επικοινωνία μέσω διαδικτύου.
